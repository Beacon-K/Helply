## Why updates matter

Most security attacks use problems that have **already been fixed** by an update. A computer that's weeks behind on updates is an easy target. Updates also fix bugs and crashes.

## Install updates on your schedule

1. Settings → **Windows Update** → **Check for updates**.
2. Let downloads finish, then click **Restart now** — or use **Schedule the restart** for lunch or the end of the day.
3. Set **Active hours** (Settings → Windows Update → Advanced options) to your working hours so Windows doesn't restart during work.

> **Tip:** Save your work and restart at the end of the day at least once or twice a week. Many "slow computer" problems are just a pending update waiting for a restart.

## "Working on updates — don't turn off your computer"

- **Leave it alone.** Some updates take 20–30 minutes (more on older computers). Keep the laptop **plugged in**.
- Only if it hasn't changed for **over an hour** (same percentage, no disk light activity): hold the power button to turn it off and start it again. Windows usually rolls back and tries again later.

## Update failed or keeps retrying

1. Restart and try **Check for updates** again.
2. Make sure you have **at least 10–20 GB free space** — see "Low disk space: how to free up room".
3. Run Settings → System → Troubleshoot → Other troubleshooters → **Windows Update**.
4. Note the **error code** shown in Windows Update history (Settings → Windows Update → **Update history**) — e.g. `0x80070002`.

## Open a ticket if

An update fails repeatedly, the computer won't start after an update, or an update broke something you rely on. Include the error code and the name/number of the update (e.g. `KB5030219`) from Update history.

## Mac

System Settings → General → **Software Update**. Keep the Mac plugged in and allow time for large macOS updates.

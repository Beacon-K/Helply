## The app is frozen right now

1. **Wait 1–2 minutes** — large files or network drives can make an app look frozen while it's still working.
2. If it doesn't recover, force it to close:
   - Windows: `Ctrl + Shift + Esc` → Task Manager → select the app → **End task**.
   - Mac: `Cmd + Option + Esc` → select the app → **Force Quit**.
3. Reopen the app. Office apps usually offer **Document Recovery** for unsaved work — check the panel on the left before closing it.

## It keeps crashing

1. **Restart the computer.**
2. **Install updates** — both Windows/macOS updates and app updates (in Office: File → Account → **Update Options → Update Now**).
3. **Does it crash with one file only?** Then the file may be damaged or very large. Try opening a copy, or a different file.
4. **Office add-ins** are a common cause. Start the app in **safe mode**: hold `Ctrl` while opening Word/Excel/Outlook and click **Yes**. If it's stable in safe mode, disable add-ins via File → Options → **Add-ins** → Manage COM Add-ins → **Go…** and untick them one at a time.

## Repair Microsoft Office (Windows)

1. Close all Office apps.
2. Settings → Apps → **Installed apps** → find **Microsoft 365** / **Microsoft Office** → `...` → **Modify**.
3. Choose **Quick Repair** first (a few minutes, no internet needed). If that doesn't help, run **Online Repair** (longer, reinstalls Office).

## Protect your work

- Turn on **AutoSave** by saving files to **OneDrive or SharePoint** — every change is saved automatically.
- Save often (`Ctrl + S`) when working on local files.

## Open a ticket if

The crashes continue after the steps above. Include: the app and version (File → Account → About), the exact error text, whether it happens with every file, and roughly how often.

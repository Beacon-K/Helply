## Why it matters

When the main drive (usually `C:`) is nearly full, the computer slows down, updates fail, and apps can crash. Aim to keep **at least 15–20% free**.

## Check how much space you have

- **Windows:** File Explorer → **This PC** — the bar under `C:` turns red when space is low. For a breakdown: Settings → System → **Storage**.
- **Mac:** Apple menu → System Settings → General → **Storage**.

## Safe ways to free space (Windows)

1. **Storage Sense / Cleanup recommendations:** Settings → System → Storage → **Cleanup recommendations** → review and clean temporary files, large unused files, and the Recycle Bin.
2. **Empty the Recycle Bin** (make sure there's nothing you need in it first).
3. **Clear the Downloads folder** — installers (`.exe`, `.msi`), old ZIPs and duplicate PDFs pile up here. Sort by **Size**.
4. **Free up OneDrive space:** right-click your OneDrive folder → **Free up space**. Files stay safe in the cloud (☁️ icon) and download again when opened.
5. **Uninstall apps you don't use:** Settings → Apps → Installed apps → sort by **Size** (you may need IT for some apps).

## Mac

System Settings → General → Storage → review the **Recommendations** (Store in iCloud/OneDrive, Optimize Storage, Empty Trash automatically), and check **Documents** for large files.

## Please don't

- Delete files from `C:\Windows`, `Program Files`, or any system folder.
- Use "cleaner" or "PC optimizer" programs from the internet — many are scareware or adware.

## Open a ticket if

Space fills up again quickly, or you can't find what's using it. Include a screenshot of Settings → System → Storage. IT can check for large hidden files (e.g. old Outlook data files, logs) and whether your laptop needs a bigger drive.

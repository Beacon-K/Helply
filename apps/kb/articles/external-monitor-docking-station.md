## Monitor says "No signal"

1. **Check the monitor is on** and set to the right **input** (use the monitor's buttons: HDMI 1 / HDMI 2 / DisplayPort / USB-C).
2. **Reseat the cables** at both ends — monitor and laptop/dock. Try a different cable or port if you have one.
3. Press `Windows + P` and choose **Extend** (or **Duplicate**). On Mac: System Settings → Displays.
4. Windows: Settings → System → Display → scroll down → **Detect** under "Multiple displays".

## Docking station problems

1. **Unplug the dock from the laptop, wait 10 seconds, plug back in.**
2. **Power-cycle the dock**: unplug its power adapter for 30 seconds. Docks hold a lot of state and this fixes most issues.
3. Check the **dock's own power adapter** is connected — USB-C docks without power often can't drive monitors.
4. Plug the laptop into the **right USB-C / Thunderbolt port** — many laptops support video and charging on only some ports (look for a ⚡ or display symbol).
5. **Restart the laptop while it's connected** to the dock.

## Flickering or wrong resolution

- Settings → System → Display → select the monitor → set **Display resolution** to the one marked "(Recommended)".
- Try `Windows + Ctrl + Shift + B` to reset the graphics driver.
- Flickering only when the cable moves → the cable is failing; ask IT for a replacement.

## Screens are in the wrong order (mouse goes off the wrong side)

Settings → System → Display → drag the numbered screen boxes to match your desk layout → **Apply**. Click **Identify** to see which number is which.

## Open a ticket if

The monitor or dock still doesn't work with a known-good cable. Include: the monitor model, the dock model, which ports you're using, and whether the monitor works with another laptop.

## Act quickly

Most deleted files can be recovered, but only for a limited time. The sooner you look, the better your chances.

## 1. Undo

If you've just deleted or moved it in File Explorer, press `Ctrl + Z` straight away.

## 2. Recycle Bin (files on your computer)

1. Open the **Recycle Bin** on the desktop (Mac: **Trash** in the Dock).
2. Find the file (sort by **Date Deleted**), right-click it → **Restore** (Mac: **Put Back**).

## 3. OneDrive or SharePoint files

Deleted files go to the online recycle bin, not your computer's:

1. Go to **OneDrive on the web** (or the SharePoint site the file was on).
2. Click **Recycle bin** in the left menu.
3. Select the file → **Restore**. It returns to its original folder.

For work accounts, Microsoft 365 generally keeps deleted items for **93 days** by default (IT can confirm your company's setting). If it's not in the first recycle bin, IT may still be able to recover it from the second-stage recycle bin — open a ticket.

## 4. Saved over a file? Use version history

OneDrive and SharePoint keep earlier versions automatically:

- In the file list, right-click the file → **Version history** → pick an older version → **Restore**.
- Or in Word/Excel/PowerPoint: File → **Info** → **Version History**.

## 5. Shared network drive (e.g. `S:` or `\\fileserver`)

Files deleted from a network drive **don't go to your Recycle Bin**. Right-click the folder that contained the file → **Properties** → **Previous Versions** tab — if available, open an older copy and copy your file out. If the tab is empty, IT can restore from backup.

## Open a ticket if you can't find it

Include:

- **File name** (or part of it) and **exact folder location**.
- **When** it was last seen or deleted, and when it was last correct.
- Whether it was on OneDrive, SharePoint, a shared drive, or only on your computer.

> **Prevention:** Files stored only on your laptop's desktop or Documents folder may not be backed up. Save work files to **OneDrive or SharePoint**.

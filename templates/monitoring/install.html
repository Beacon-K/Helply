    What the agent does
    • Sends CPU, memory, disk, network, load and uptime every 10 seconds over HTTPS.
    • Only sends. No open ports; Helply cannot run commands on the server.
    • Reads the provider's own metadata service once to learn region and machine type.
    • Runs unprivileged, capped at 64 MB. One readable file: helply_agent.py. Remove it with --uninstall / -Uninstall.
